# Critter Match

A cheerful 6×6 memory matching game built for a 7-year-old, with 18 critter pairs (🦄🐸🐙🦋🐳🦁🐼🦊🐨🐰🦉🐢🐬🦖🐝🐧🐌🦀) to find.

Play by opening `index.html` in a browser, or enable GitHub Pages on this repo for a shareable link.

## Features

- Three difficulty levels: Easy (4×4, 8 pairs), Medium (6×4, 12 pairs), Hard (6×6, 18 pairs)
- Brief "memorize" preview at the start of each game
- Sound effects (with a mute toggle) and haptic-style feedback
- Confetti celebration and a star rating when you win
- Tracks matches, tries, and time
- Works on phones and respects reduced-motion settings

## Tech

Single self-contained `index.html` — no build step, no dependencies. Just open it.
